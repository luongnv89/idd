# v0.10.1 — Skill version corrections

Released: 2026-06-03

## What's New

A maintenance release that aligns each skill's `metadata.version` with the
behavior fixes that already shipped in 0.10.0. No new behavior — 0.10.0 carried
the fixes but did not tick the affected skills' own version numbers, so this
release corrects them and keeps the README skill table in sync.

Skill versions bumped:

- `/issue-resolver` 0.7.1 → 0.7.2 — correct subagent invocation (#95)
- `/issue-pr-review` 0.5.0 → 0.5.1 — correct subagent invocation (#95)
- `/auto-pilot` 2.3.0 → 2.3.1 — never pass a skill name as `subagent_type` (#98, #99)

These fixes resolve the "Agent type not found" error: shared agents must be
spawned with the Agent tool passing only `description` and `prompt` (the shared
agent prompt), never a `subagent_type` of a shared-agent or skill name.
