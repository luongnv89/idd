# v0.10.0 — Dependency-aware merge gate for auto-pilot

Released: 2026-05-04

## What's New

**Phase 5 dependency-aware merge gate in `/auto-pilot`** (#93)

Before merging any PR, the auto-pilot loop now parses `Depends on #N` and `Blocked by #N` markers from the originating issue's body and verifies that every referenced issue is closed and its PR merged. If any dependency is unsatisfied, the loop pauses with a structured alert (mirroring the existing critical-issue alert shape) and leaves the PR open — the user resolves the dependency, then re-runs `/auto-pilot` to resume.

Key details:

- New iteration outcome label: `blocked_by_dependency`
- New config key: `autopilot.respect_dependencies: true` (default on; set to `false` to disable the gate)
- Self-referencing cycle detection skips the gate to avoid infinite pauses
- Multi-hop cycles surface as repeated `blocked_by_dependency` outcomes
- Cross-repo dependency references are out of scope
- The dependency convention is documented in `docs/idd-methodology.md` (Issue Dependencies section)

Skill version bumped: `/auto-pilot` 2.2.0 → 2.3.0
