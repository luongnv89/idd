# Init Gitissue Runbook

This reference holds the detection details and config field guidance out of the main body.

## Detection

- Prefer manifest files and existing repo conventions.
- Infer the test runner from the project’s tooling.
- Favor small, safe defaults over overfitting.

## Output

Write a concise `.gitissue.yml` that captures only the repository-specific defaults the rest of the skills need.
